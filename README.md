#----index.tsx

-это главная точка входа которая имеет внутри подключение всех страниц с помощью REACTNAVIGATION и боковых рамок для адаптации

#---CardPlace

-имеет внутри список  по типа места по типа кафе, ресторан и т.д. имеет функцию\интерфей\класс для мест который имеет внутри себя 
-названия, описание, тип места и т.д. так же снизу есть мок дата с кучей мест чтобы не было пусто при первом заходе

#---Places

-имеет внутри себя масив всех мест, масив айдишников избранных мест, функции для добавления места, добавления и удаления из -избранного, так же он записывает внутри себя мок дату из файла CardPlace

#---LocatinHook

-нужен для запроса на предоствелиние доступа к местоположению, записывает и возвращает ошибку либо местоположение
-это типо хук который будет использоваться внутри LocationPage

#---MainPage

-отображает все карточки, имеет простую пагинацию по 10 карточек, фильтры по айдишникам избранных товаров, кнопки для перехода на
-LocationPage AddPlacePAge и т.д.

#---LocatonPage

-использует псевдохук LocationHook чтобы вызвать панель на предоставление доступа к местопложению или вывод ошибки

#---AddPlacePage

-Панель для добавления нового элемента, наследует функцию для добавления элемента в масив из Places.ts

#---DetailsPage

-Панель которая отображает детали места, используеться в самой карточке в файле CardPlace
